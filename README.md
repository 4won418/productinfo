# 📦 상품 정보 맵 (Product Map)

KANGOL 브랜드의 8,000+ 상품을 한눈에 조회하고 상세 정보를 확인할 수 있는 웹 기반 상품 카탈로그 시스템입니다.

## 🎯 특징

- **빠른 검색**: 수입품번, 품번, 품명, 기획명, 복종명으로 실시간 검색
- **스마트 필터**: 시즌, 기획명, 복종명으로 여러 항목 동시 필터링
- **상세 정보**: 클릭 시 상품의 모든 정보 (A~R 열, 18개 항목) 표시
- **반응형 디자인**: 데스크톱, 태블릿, 모바일 모두 지원
- **빠른 로드**: 클라이언트 사이드 처리로 서버 비용 최소화

## 🎨 주요 기능

### 1. 필터링 (Filter)
- **시즌**: 24SS, 24AW, 25SS, 25AW, 26SS, 26AW (복수 선택)
- **기획명**: 가방, 신발 등 (복수 선택)
- **복종명**: KANGOL DOLL 등 (복수 선택)

### 2. 검색 (Search)
다음 항목으로 실시간 검색:
- 수입품번
- 품번
- 품명
- 기획명
- 복종명

### 3. 상품 카드 (Product Card)
다음 정보 표시:
- 상품 이미지
- 수입품번
- 품명
- 기획명 / 복종명
- 최초가

### 4. 상세 정보 (Detail Modal)
카드 클릭 시 모달 팝업에서:
- 상품 이미지 (확대)
- 18개의 모든 정보
  - 기본정보: 시즌, 년도, 기획, 복종, 수입품번, 품번, 품명
  - 상품특성: 색상, 사이즈
  - 공급정보: 발주처, 원산지, 디자이너
  - 가격정보: 최초가, 택가, 사후원가(V+)
  - 날짜: 최초입고일, 최초출고일

## 🐛 트러블슈팅

### 상품 이미지가 안 보이는 경우
- 상품이미지 폴더 구조 확인
- 브라우저 콘솔(F12)에서 404 에러 확인
- GitHub에 이미지 폴더가 업로드되었는지 확인

### 데이터가 로드 안 되는 경우
- `product_data.json` 파일이 Repository에 있는지 확인
- Network 탭에서 JSON 요청 상태 확인
- GitHub Raw URL이 정확한지 확인

### GitHub Pages가 활성화 안 된 경우
- Repository Settings → Pages 확인
- Branch가 `main`으로 설정되어 있는지 확인
- Source가 `/ (root)`로 설정되어 있는지 확인
