# 📦 KANGOL PRODUCT INFO

KANGOL 브랜드의 1,400+ 품번을 한눈에 조회하고 상세 정보(색상별 발주/입고 수량 포함)를 확인할 수 있는 웹 기반 상품 카탈로그 시스템입니다.

**🔗 라이브 페이지**: https://4won418.github.io/productinfo/

---

## 🎯 특징

- **품번 단위 카드**: 색상/사이즈로 나뉘어 있던 원본 데이터를 품번 기준으로 그룹화해 하나의 카드로 표시
- **계층형 필터**: 기획명을 선택하면 그에 속한 복종명만 드롭다운에 표시 (예: 의류 선택 시 가방류 복종명은 제외)
- **빠른 검색**: 수입품번, 품번, 품명, 기획명, 복종명으로 실시간 검색
- **상세 정보 + 수량 집계**: 클릭 시 상품 기본정보 18개 항목과 **색상별 발주/입고 수량 테이블(TOTAL 포함)** 표시
- **반응형 디자인**: 데스크톱, 태블릿, 모바일 모두 지원
- **빠른 로드**: 클라이언트 사이드 처리로 서버 비용 없음 (GitHub Pages 무료 호스팅)
- **검색 엔진 비노출**: `robots`/`googlebot` meta 태그로 외부 검색 결과에서 제외

## 🚀 시작하기

### 온라인 (GitHub Pages)

브라우저에서 바로 열기:
```
https://4won418.github.io/productinfo/
```

### 로컬 실행

1. 이 Repository를 Clone:
```bash
git clone https://github.com/4won418/productinfo.git
cd productinfo
```

2. 로컬 HTTP 서버 실행 (file:// 직접 열기는 CORS로 인해 데이터 로드 불가):
```bash
python -m http.server 8000
```

3. 브라우저 열기:
```
http://localhost:8000/index.html
```

> 참고: `index.html`은 기본적으로 GitHub Raw URL(`raw.githubusercontent.com`)에서 데이터를 fetch하도록 설정되어 있어, GitHub에 최신 데이터가 반영되어 있어야 정상 동작합니다.

## 📁 파일 구조

```
productinfo/
├── index.html                  # 메인 웹 페이지 (GitHub Pages 진입점)
├── product_data.json           # 원본 상품 데이터 (색상/사이즈별 8,065행)
├── README.md                   # 이 파일
└── product-images/             # 상품 이미지 (시즌 폴더는 영문/숫자만 사용)
    ├── 24SS/                   # 2024 봄/여름
    ├── 24AW/                   # 2024 가을/겨울
    ├── 25SS/                   # 2025 봄/여름
    ├── 25AW/                   # 2025 가을/겨울
    ├── 26SS/                   # 2026 봄/여름
    └── 26AW/                   # 2026 가을/겨울
```

이미지 파일명은 `품번.jpg` 형식이며, 페이지 내부에서는 `년도명 뒤 2자리 + 시즌코드(SS/AW)`로 폴더를 매핑합니다. (예: 년도명 `2024` + 시즌명 `봄/여름` → `24SS` 폴더)

## 🎨 주요 기능

### 1. 필터링 (Filter)
- **시즌**: 24SS, 24AW, 25SS, 25AW, 26SS, 26AW (복수 선택, 배지형)
- **기획명**: 가방, 수입모자, 의류, 의류(여성) 등 (복수 선택, 배지형)
- **복종명**: 드롭다운 클릭 시 체크박스 목록 표시, **선택된 기획명에 속한 복종명만 노출**되는 계층형 필터 (복수 선택)

### 2. 검색 (Search)
다음 항목으로 실시간 검색:
- 수입품번 / 품번 / 품명 / 기획명 / 복종명

### 3. 상품 카드 (Product Card)
품번 단위로 그룹화되어 표시:
- 상품 이미지
- **품번** (강조), 품명
- 기획명 · 복종명 · 수입품번 · 최초가 (동일한 배지 스타일로 나열)

### 4. 상세 정보 모달 (Detail Modal)
카드 클릭 시:
- 상품 이미지 (확대)
- 기본정보: 시즌명, 년도명, 기획명, 복종명, 수입품번, 품번, 품명, 발주처명, 원산지명, 디자이너, 최초가, 택가, 사후원가(V+), 최초입고일, 최초출고일
- **색상별 발주수량 · 입고수량 테이블** (예: BK / WH / NV ... + TOTAL 행)

## 🐛 트러블슈팅

### 상품 이미지가 안 보이는 경우
- `product-images/` 폴더가 Repository에 업로드되어 있는지 확인 (웹 업로드는 100개 파일 제한이 있어 GitHub Desktop으로 업로드 권장)
- 폴더명이 `24SS`, `24AW` 등 영문+숫자 조합인지 확인 (한글 폴더명은 URL 인코딩 문제로 이미지가 깨질 수 있음)
- 브라우저 콘솔(F12) → Network 탭에서 이미지 요청이 404인지 확인

### 데이터가 로드 안 되는 경우
- `product_data.json`이 Repository에 있는지 확인
- `index.html` 내 `GITHUB_RAW_URL` 값이 실제 계정/Repository명과 일치하는지 확인
  ```js
  const GITHUB_RAW_URL = 'https://raw.githubusercontent.com/4won418/productinfo/main';
  ```

### GitHub Pages가 404가 뜨는 경우
- Repository → Settings → Pages에서 **Branch가 `main`**, **Source가 `/ (root)`**로 설정되어 있는지 확인
- GitHub Desktop에서 **Publish branch / Push origin**을 실제로 눌렀는지 확인 (커밋만 하고 푸시를 안 하면 로컬에만 저장됨)
